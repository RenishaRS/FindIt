# FindIt - Campus Lost & Found

FindIt is a web-based campus Lost & Found application that helps students report, search, and manage lost and found items within their campus.

🌐 **Live Demo:** [Open FindIt](https://findit-wp5y.onrender.com)

## Features

- Report lost items
- Report found items
- Upload item photos
- Search for reported items
- Filter items by Lost or Found
- View detailed item information
- Track item status as Active or Claimed
- Store item information using SQLite database

## Technologies Used

- HTML
- CSS
- Python
- Flask
- SQLite
- Git & GitHub
